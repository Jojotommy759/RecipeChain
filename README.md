# RecipeChain

A decentralized culinary recipe and cooking technique exchange platform for sharing culinary knowledge on Stacks blockchain.

## Features

- Recipe sharing with comprehensive cooking instructions
- Chef skill level management and validation
- Cuisine type classification system
- Cook time specification and tracking
- Recipe privacy management and sharing controls

## Smart Contract Functions

### Public Functions
- `share-recipe` - Share new culinary recipe with instructions
- `make-private-recipe` - Make recipe private (chef only)

### Read-Only Functions
- `get-recipe` - Get culinary recipe details
- `get-chef` - Get recipe chef information
- `get-total-recipes` - Get total shared recipes
- `get-sharing-status` - Get recipe sharing status

## Cuisine Types
- Italian, French, Asian, Mexican, Mediterranean, American

## Skill Levels
- Beginner, Easy, Moderate, Advanced, Expert

## Usage

Deploy the contract to create a culinary recipe platform where chefs can share their recipes and manage privacy settings throughout the cooking community.
